Migration PROD — MDM

Projet bdcmdm26 · copie des collections personnelles vers les collections partagées (modèle équipe), avec ajout du propriétaire. Ne supprime jamais les collections d'origine.
Rappel : lance d'abord la Simulation (aucune écriture) pour vérifier les volumes. Le mode Appliquer écrit dans les collections partagées *_mdm ; tes collections personnelles *_mdm_<uid> restent intactes. L'opération est ré-exécutable sans créer de doublons.
Le bouton « Appliquer » s'active après une simulation réussie.
